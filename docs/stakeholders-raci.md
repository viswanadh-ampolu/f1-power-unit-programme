## RACI — key decisions & deliverables

**R** = Responsible · **A** = Accountable (one per row) · **C** = Consulted · **I** = Informed

| Activity | PgM | Tech Dir | ICE Lead | ERS Lead | Dyno Eng | Cost/FIA | Race Ops |
|---|:--:|:--:|:--:|:--:|:--:|:--:|:--:|
| Approve PU architecture | C | **A** | R | C | C | C | I |
| Dyno schedule & allocation | **A**/R | I | C | C | C | I | I |
| Reliability sign-off for homologation | C | **A** | C | C | R | C | I |
| Cost-cap trade-off decisions | C | **A** | C | C | I | R | I |
| FIA homologation submission | C | A | C | C | C | **A**/R | I |
| Go/no-go for round 1 deployment | R | **A** | C | C | C | C | C |
| In-season element allocation calls | **A**/R | C | C | C | C | I | C |
| Status reporting | **A**/R | I | C | C | C | C | C |

> In a cost-capped, homologated programme the **Accountable** column matters more than
> usual: when a reliability fix and a cost-cap limit collide, everyone must know it's the
> Technical Director's call — made with a recommendation from me, on the record.
