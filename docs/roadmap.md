# Roadmap — Project Apex (2026 Power Unit)

Everything pulls toward two fixed dates: the **FIA homologation deadline** and
**round 1** of the season. The plan is built backwards from those.

## Now / Next / Later

### 🟢 Now (concept & architecture)
- Down-select ICE architecture candidates after rig testing (ICE)
- Lock sustainable-fuel calibration targets with supplier (ICE)
- First ERS deployment map + battery thermal model (ERS)
- Build the cost model against the PU cost cap (Compliance)
- Baseline dyno plan & allocation across workstreams (Reliability)

### 🟡 Next (validation & homologation)
- Accumulate dyno mileage toward reliability target (Reliability)
- Integrate ERS + ICE on full-PU dyno (ICE + ERS)
- Failure analysis loop on each stoppage; close reliability gaps (Reliability)
- Assemble and submit **FIA homologation dossier** (Compliance)

### 🔵 Later (deployment & season)
- Pre-season testing (install, telemetry, shakedown)
- Round 1 deployment; in-season support
- Manage element allocation across the calendar; lessons-learned after each race

## Critical path
`M1 → M3 (first fire on dyno) → M4 (reliability target) → HOMOLOGATION GATE → M5 (testing) → M6 (round 1)`

The programme lives or dies on **M3 → M4 → Gate**: reliability mileage must be banked
*before* the design is locked at homologation. The dyno is the shared bottleneck feeding
all of it — see RAID items **R-01** and **R-03**.
